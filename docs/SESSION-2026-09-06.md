## Known limits worth knowing

- `ci main` shows `n/a` until M6 (never faked).
- The fixture's "running" run has a fixed start time, so its duration grows with the clock.
- `strip.unpushed` for the fixture reads the *monorepo's* git state (the fixture is not
  its own repo); real projects read their own.
- Placeholder detection is a heuristic (`<…>` tokens, `<slug>` excluded); a filled doc
  that legitimately contains angle brackets would show as `wip`.
